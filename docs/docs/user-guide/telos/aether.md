# Aether

Aether currently opens a local preview. Real Nostr account management, relay
connections, feeds and settings are not yet available in released Telos builds.

A full Amethyst client is being adapted into a library inside the Telos source
tree. The intended integration runs inside the Telos APK and will not require
an external Amethyst application. It is not enabled in production yet.

See the [integration status](../../developer-guide/aether-amethyst.md) for the
remaining implementation and validation work.
